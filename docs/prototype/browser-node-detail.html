退款时效策略 PRD

ZY 产品团队 · 更新于 2026-08-18

本文档定义退款申请进入人工审核的触发条件，以及超时后的客服协同方式。现行策略需要同时考虑订单风险等级、支付渠道和用户历史行为。

2. 人工审核时效

核心规则：

退款申请提交后超过 24 小时仍未完成自动校验时，必须进入人工审核队列。

人工审核任务由支付风控组接收，工作日 09:00–18:00 内需要在 2 小时内首次处理。非工作时段产生的任务顺延至下一工作日。

3. 状态通知

当订单进入人工审核后，客户端展示“退款处理中”。 服务端只发送一次状态变更通知，并在退款结果确定后发送最终结果。

  • 审核通过：进入原渠道退款。
  • 需要补充材料：创建客服跟进任务。
  • 审核拒绝：记录原因并通知用户。
